发布脚本：推送重试 + 代理探测 + 两端互不阻塞

真实发布 v0.3.0 时遇到 github.com 直连被重置，暴露出三个问题，都已修掉：

1. 重试的 sleep 用了 unref 过的定时器，不维持事件循环，顶层 await 报
   Detected unsettled top-level await，重试根本没有发生。
2. 一个平台失败会中断整个脚本，Gitee 明明能推也被跳过。改为各自 try/catch，
   失败记下来继续，最后汇总报告并以 exit code 2 结束。
3. 没有代理支持。新增 VMPROBE_GIT_PROXY 显式指定，或自动探测本机
   7890/7891 代理端口（通了才用，不猜）。对本机很重要：
   GitHub 直连时通时不通，而 Gitee 一直正常。
